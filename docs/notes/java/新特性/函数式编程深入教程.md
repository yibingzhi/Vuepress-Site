# 函数式编程深入教程

本文档配合`com.ibz.functional`包中的Java文件，详细介绍Java函数式编程的核心概念、API使用和实际应用。

## 函数式编程基础概念

函数式编程（Functional Programming）是一种编程范式，它将计算视为数学函数的求值，避免了改变状态和可变数据。Java 8引入了函数式编程的特性，包括Lambda表达式、Stream API、Optional类和CompletableFuture类等。

### 函数式编程的核心特性

1. **不可变性**：数据一旦创建就不能被修改
2. **纯函数**：函数的输出只依赖于输入，没有副作用
3. **函数是一等公民**：函数可以作为参数传递、作为返回值返回
4. **惰性求值**：只在需要时才计算值
5. **递归**：使用递归而不是循环来处理数据

### Java中的函数式编程特性

Java 8及以后版本提供了以下函数式编程特性：

1. **Lambda表达式**：简洁地定义匿名函数
2. **函数式接口**：只包含一个抽象方法的接口
3. **Stream API**：处理数据集合的函数式方法
4. **Optional类**：避免空指针异常的容器类
5. **CompletableFuture类**：异步编程的支持
6. **方法引用**：引用已有方法的简洁语法

## Lambda表达式

Lambda表达式是Java 8引入的重要特性，它允许我们将函数作为参数传递给方法，或者将代码作为数据处理。

### Lambda表达式语法

Lambda表达式的语法格式为：
```
(参数列表) -> { 函数体 }
```

根据函数体的复杂程度，有以下几种形式：

1. **单表达式**：`(parameters) -> expression`
2. **代码块**：`(parameters) -> { statements; }`
3. **无参数**：`() -> expression`
4. **单参数**：`parameter -> expression`

### Lambda表达式示例

```java
// 传统匿名内部类方式
Runnable traditionalRunnable = new Runnable() {
    @Override
    public void run() {
        System.out.println("传统方式执行任务");
    }
};

// Lambda表达式方式
Runnable lambdaRunnable = () -> System.out.println("Lambda方式执行任务");

// 带参数的Lambda表达式
Comparator<String> comparator = (s1, s2) -> s1.compareTo(s2);

// 带多行代码的Lambda表达式
Consumer<String> multiLineConsumer = (name) -> {
    System.out.println("处理名字: " + name);
    System.out.println("名字长度: " + name.length());
};
```

## 函数式接口

函数式接口是只包含一个抽象方法的接口，可以用作Lambda表达式的类型。Java在`java.util.function`包中提供了许多常用的函数式接口。

### 核心函数式接口

1. **Predicate<T>**：接受一个参数并返回boolean
```java
Predicate<Integer> isEven = n -> n % 2 == 0;
boolean result = isEven.test(4); // true
```

2. **Function<T, R>**：接受一个参数并返回结果
```java
Function<String, Integer> stringToLength = s -> s.length();
Integer length = stringToLength.apply("Hello"); // 5
```

3. **Consumer<T>**：接受一个参数但不返回结果
```java
Consumer<String> printer = s -> System.out.println(s);
printer.accept("Hello"); // 打印Hello
```

4. **Supplier<T>**：不接受参数但返回结果
```java
Supplier<Double> randomSupplier = () -> Math.random();
Double random = randomSupplier.get(); // 随机数
```

5. **UnaryOperator<T>**：接受和返回相同类型的参数
```java
UnaryOperator<Integer> square = n -> n * n;
Integer result = square.apply(5); // 25
```

6. **BinaryOperator<T>**：接受两个相同类型的参数并返回相同类型的结果
```java
BinaryOperator<Integer> add = (a, b) -> a + b;
Integer result = add.apply(3, 4); // 7
```

## 方法引用

方法引用提供了另一种简洁的方式来引用已有方法或构造器，它是Lambda表达式的简化写法。

### 方法引用的类型

1. **静态方法引用**：`ClassName::staticMethod`
```java
names.forEach(System.out::println);
```

2. **实例方法引用**：`instance::method`
```java
String prefix = "姓名: ";
names.stream().map(prefix::concat).forEach(System.out::println);
```

3. **特定类型任意对象的实例方法引用**：`ClassName::method`
```java
names.sort(String::compareToIgnoreCase);
```

4. **构造方法引用**：`ClassName::new`
```java
Supplier<List<String>> listSupplier = ArrayList::new;
Function<Integer, List<String>> sizedListSupplier = ArrayList::new;
```

## Stream API

Stream API是Java 8引入的用于处理数据集合的函数式API，它提供了一种声明式的方式来处理数据。

### Stream的创建

Stream可以通过多种方式创建：

1. **从集合创建**：
```java
List<String> names = Arrays.asList("张三", "李四", "王五");
Stream<String> stream = names.stream();
```

2. **从数组创建**：
```java
String[] nameArray = {"钱七", "孙八", "周九"};
Stream<String> stream = Arrays.stream(nameArray);
```

3. **使用Stream.of创建**：
```java
Stream<String> stream = Stream.of("甲", "乙", "丙");
```

4. **创建无限流**：
```java
// 迭代无限流
Stream<Integer> infiniteStream = Stream.iterate(0, n -> n + 2);
List<Integer> evenNumbers = infiniteStream.limit(5).collect(Collectors.toList());

// 生成无限流
Stream<Double> randomStream = Stream.generate(Math::random);
List<Double> randomNumbers = randomStream.limit(3).collect(Collectors.toList());
```

### Stream的操作类型

Stream操作分为两类：

1. **中间操作（Intermediate Operations）**：返回Stream，可以链式调用
2. **终端操作（Terminal Operations）**：返回结果或副作用，结束Stream

### 中间操作

1. **filter**：过滤元素
```java
List<Integer> evenNumbers = numbers.stream()
        .filter(n -> n % 2 == 0)
        .collect(Collectors.toList());
```

2. **map**：转换元素
```java
List<Integer> squares = numbers.stream()
        .map(n -> n * n)
        .collect(Collectors.toList());
```

3. **flatMap**：扁平化映射
```java
List<List<Integer>> listOfLists = Arrays.asList(
        Arrays.asList(1, 2),
        Arrays.asList(3, 4),
        Arrays.asList(5, 6)
);
List<Integer> flattened = listOfLists.stream()
        .flatMap(List::stream)
        .collect(Collectors.toList());
```

4. **distinct**：去重
```java
List<Integer> distinctNumbers = withDuplicates.stream()
        .distinct()
        .collect(Collectors.toList());
```

5. **sorted**：排序
```java
List<Integer> sorted = unsorted.stream()
        .sorted()
        .collect(Collectors.toList());
```

6. **peek**：调试
```java
List<Integer> peeked = numbers.stream()
        .filter(n -> n > 5)
        .peek(n -> System.out.println("过滤后的数字: " + n))
        .collect(Collectors.toList());
```

### 终端操作

1. **forEach**：遍历
```java
numbers.stream()
        .filter(n -> n % 2 == 0)
        .forEach(n -> System.out.print(n + " "));
```

2. **reduce**：归约
```java
Optional<Integer> sum = numbers.stream()
        .reduce((a, b) -> a + b);
```

3. **collect**：收集
```java
List<Integer> collected = numbers.stream()
        .filter(n -> n % 2 == 0)
        .collect(Collectors.toList());
```

4. **min, max, count**：最值和计数
```java
Optional<Integer> min = numbers.stream().min(Integer::compareTo);
Optional<Integer> max = numbers.stream().max(Integer::compareTo);
long count = numbers.stream().count();
```

5. **匹配操作**：
```java
boolean hasEven = numbers.stream().anyMatch(n -> n % 2 == 0);
boolean allEven = numbers.stream().allMatch(n -> n % 2 == 0);
boolean noneNegative = numbers.stream().noneMatch(n -> n < 0);
```

6. **查找操作**：
```java
Optional<Integer> first = numbers.stream().findFirst();
Optional<Integer> any = numbers.stream().findAny();
```

## Collectors收集器

Collectors类提供了许多预定义的收集器，用于将Stream元素收集到集合或其他数据结构中。

### 常用收集器

1. **toList, toSet**：
```java
List<String> names = people.stream()
        .map(Person::getName)
        .collect(Collectors.toList());
Set<Integer> ages = people.stream()
        .map(Person::getAge)
        .collect(Collectors.toSet());
```

2. **toMap**：
```java
Map<String, Integer> nameToAge = people.stream()
        .collect(Collectors.toMap(Person::getName, Person::getAge));
```

3. **groupingBy**：
```java
Map<Integer, List<Person>> groupByAge = people.stream()
        .collect(Collectors.groupingBy(Person::getAge));
```

4. **partitioningBy**：
```java
Map<Boolean, List<Person>> partitionByAge = people.stream()
        .collect(Collectors.partitioningBy(p -> p.getAge() >= 30));
```

5. **统计收集器**：
```java
IntSummaryStatistics stats = people.stream()
        .collect(Collectors.summarizingInt(Person::getAge));
```

6. **joining**：
```java
String joinedNames = people.stream()
        .map(Person::getName)
        .collect(Collectors.joining(", "));
```

## 并行流

并行流可以利用多核处理器并行处理数据，提高处理效率。

### 并行流的使用

```java
// 顺序流
long sequentialSum = numbers.stream()
        .reduce(0L, Long::sum);

// 并行流
long parallelSum = numbers.parallelStream()
        .reduce(0L, Long::sum);
```

### 并行流的注意事项

1. **状态问题**：并行流可能改变元素处理顺序
```java
// 顺序处理
list.stream().forEach(n -> System.out.print(n + " "));

// 并行处理（顺序可能不同）
list.parallelStream().forEach(n -> System.out.print(n + " "));

// 并行流保持顺序
list.parallelStream().forEachOrdered(n -> System.out.print(n + " "));
```

2. **性能考虑**：并行流并不总是更快，对于小数据集可能反而更慢

## Optional类

Optional类是一个容器对象，它可能包含或不包含非null值，用于避免空指针异常。

### Optional的创建

```java
// 创建包含值的Optional
Optional<String> optionalWithValue = Optional.of("Hello");

// 创建可能为空的Optional
Optional<String> optionalNullable = Optional.ofNullable(null);

// 创建空的Optional
Optional<String> emptyOptional = Optional.empty();
```

### Optional的操作

1. **检查值**：
```java
boolean isPresent = optional.isPresent();
boolean isEmpty = optional.isEmpty(); // Java 11+
```

2. **获取值**：
```java
String value = optional.orElse("默认值");
String value2 = optional.orElseGet(() -> "Supplier提供的默认值");
String value3 = optional.orElseThrow(() -> new RuntimeException("值不存在"));
```

3. **条件操作**：
```java
optional.ifPresent(s -> System.out.println("值存在: " + s));
```

4. **转换操作**：
```java
Optional<Integer> lengthOptional = optional.map(String::length);
Optional<String> nameOptional = personOptional.flatMap(Person::getNameOptional);
Optional<Integer> evenNumberOptional = numberOptional.filter(n -> n % 2 == 0);
```

## CompletableFuture

CompletableFuture是Java 8引入的用于异步编程的类，它实现了Future和CompletionStage接口。

### CompletableFuture的创建

```java
// 已完成的CompletableFuture
CompletableFuture<String> completedFuture = CompletableFuture.completedFuture("已完成的值");

// 异步执行无返回值的任务
CompletableFuture<Void> runAsyncFuture = CompletableFuture.runAsync(() -> {
    // 执行任务
});

// 异步执行有返回值的任务
CompletableFuture<String> supplyAsyncFuture = CompletableFuture.supplyAsync(() -> {
    return "结果";
});
```

### CompletableFuture的链式操作

1. **thenApply**：转换结果
```java
CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> "Hello")
        .thenApply(s -> s + " World")
        .thenApply(String::toUpperCase);
```

2. **thenCompose**：扁平化转换
```java
CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> "Hello")
        .thenCompose(s -> CompletableFuture.supplyAsync(() -> s + " World"));
```

3. **thenAccept**：消费结果
```java
CompletableFuture<Void> future = CompletableFuture.supplyAsync(() -> "Hello World")
        .thenAccept(System.out::println);
```

### CompletableFuture的组合操作

1. **thenCombine**：组合两个CompletableFuture的结果
```java
CompletableFuture<String> combinedFuture = future1.thenCombine(future2, (s1, s2) -> s1 + " " + s2);
```

2. **allOf**：等待所有CompletableFuture完成
```java
CompletableFuture<Void> allOfFuture = CompletableFuture.allOf(future1, future2, future3);
```

3. **anyOf**：等待任一CompletableFuture完成
```java
CompletableFuture<Object> anyOfFuture = CompletableFuture.anyOf(future1, future2);
```

### CompletableFuture的异常处理

```java
// exceptionally - 处理异常
CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
    throw new RuntimeException("异常");
}).exceptionally(throwable -> "异常时的默认值");

// handle - 处理结果或异常
CompletableFuture<String> future2 = CompletableFuture.supplyAsync(() -> "结果")
        .handle((result, throwable) -> {
            if (throwable != null) {
                return "异常处理结果";
            }
            return result;
        });
```

## 函数组合

函数组合是函数式编程的重要概念，它允许我们将简单函数组合成复杂函数。

### Function组合

```java
Function<Integer, Integer> multiplyByTwo = x -> x * 2;
Function<Integer, Integer> addTen = x -> x + 10;

// 先乘以2再加10
Function<Integer, Integer> multiplyThenAdd = multiplyByTwo.andThen(addTen);

// 先加10再乘以2
Function<Integer, Integer> addThenMultiply = multiplyByTwo.compose(addTen);
```

### Predicate组合

```java
Predicate<Integer> isEven = x -> x % 2 == 0;
Predicate<Integer> isPositive = x -> x > 0;

// 既是偶数又是正数
Predicate<Integer> isEvenAndPositive = isEven.and(isPositive);

// 是偶数或者正数
Predicate<Integer> isEvenOrPositive = isEven.or(isPositive);

// 非偶数
Predicate<Integer> isNotEven = isEven.negate();
```

## 最佳实践

### 1. 合理使用Lambda表达式

```java
// 好的做法：简洁的Lambda表达式
names.forEach(System.out::println);

// 避免：复杂的Lambda表达式，应该提取为方法
names.forEach(name -> {
    // 复杂的逻辑
    // 应该提取为独立方法
});
```

### 2. 正确使用Stream API

```java
// 好的做法：链式操作
List<String> result = names.stream()
        .filter(name -> name.length() > 2)
        .map(String::toUpperCase)
        .sorted()
        .collect(Collectors.toList());

// 避免：在Stream中修改外部状态
List<String> result = new ArrayList<>();
names.stream().forEach(name -> result.add(name.toUpperCase())); // 不推荐
```

### 3. 合理使用Optional

```java
// 好的做法：作为方法返回值
public Optional<String> findUserById(int id) {
    // 查找用户逻辑
    return Optional.ofNullable(user);
}

// 避免：将Optional用作方法参数
public void processUser(Optional<User> userOptional) { // 不推荐
    // 处理逻辑
}
```

### 4. 正确使用CompletableFuture

```java
// 好的做法：使用自定义线程池
CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
    // 异步任务
}, executor);

// 避免：使用默认的ForkJoinPool
CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
    // 异步任务
}); // 可能影响其他任务
```

## 总结

函数式编程为Java带来了更简洁、更易读的代码风格。通过Lambda表达式、Stream API、Optional类和CompletableFuture类，我们可以：

1. **简化代码**：减少样板代码，提高代码可读性
2. **提高效率**：利用并行流提高数据处理效率
3. **避免异常**：使用Optional避免空指针异常
4. **异步处理**：使用CompletableFuture简化异步编程
5. **函数组合**：通过函数组合构建复杂逻辑

掌握函数式编程对于现代Java开发者来说至关重要，它不仅能够提高代码质量，还能帮助我们更好地利用多核处理器的计算能力。

在实际开发中，我们应该：
- 合理使用Lambda表达式，避免过于复杂的逻辑
- 充分利用Stream API进行数据处理
- 使用Optional避免空指针异常
- 利用CompletableFuture进行异步编程
- 遵循函数式编程的最佳实践

- 理解函数式编程的核心概念
- 熟练使用Lambda表达式和函数式接口
- 掌握Stream API的使用方法
- 合理使用Optional类处理空值
- 使用CompletableFuture进行异步编程
