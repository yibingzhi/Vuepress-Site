::: tip 保鲜说明（2026-08）
JDK **21** 是当前主流 LTS（2023-09 发布，支持至 2031），**17** 仍是大量存量系统的基线。新项目优先选 **21**；从 8/11 迁移时建议先到 17 验证，再升到 21 启用虚拟线程。本文示例基于 JDK 21 语法，在 17 上不可用的特性会单独标注。
:::

## 1. LTS 版本全景

| 版本 | 发布时间 | LTS | 支持截止（Oracle） | 定位 |
|------|----------|-----|-------------------|------|
| Java 8 | 2014-03 | ✅ | 2030（商用需订阅） | 存量最多，lambda/Stream 起点 |
| Java 11 | 2018-09 | ✅ | 2032 | 模块化、HTTP Client |
| **Java 17** | 2021-09 | ✅ | 2029 | Records、Sealed、Switch 增强 |
| **Java 21** | 2023-09 | ✅ | 2031 | 虚拟线程、有序集合、Pattern Matching 完整 |

**推荐策略**：

- **2026 年新项目**：直接 `maven.compiler.release=21`，启用虚拟线程。
- **存量 8/11**：先升 17（无虚拟线程），跑通测试后再评估 21。
- **容器镜像**：`eclipse-temurin:21-jre-alpine` 或 `amazoncorretto:21-alpine`。

```xml
<!-- pom.xml -->
<properties>
    <java.version>21</java.version>
    <maven.compiler.release>21</maven.compiler.release>
</properties>
```

## 2. Records：不可变数据载体

JDK 16 正式、17 起广泛使用。适合 DTO、值对象、事件载荷。

```java
public record UserDto(Long id, String username, String email) {
    // 紧凑构造器：参数校验
    public UserDto {
        Objects.requireNonNull(username, "username");
        if (email != null && !email.contains("@")) {
            throw new IllegalArgumentException("invalid email");
        }
    }

    // 可添加静态工厂
    public static UserDto of(Long id, String username) {
        return new UserDto(id, username, null);
    }
}
```

编译器自动生成：`equals`/`hashCode`/`toString`/访问器（无 `get` 前缀，直接 `user.username()`）。

**注意**：Record 是 `final` 类，不能继承；可实现接口。JPA 实体仍建议用普通类 + Lombok，Record 更适合 API 层与领域事件。

## 3. Sealed Classes：受限继承

JDK 17 正式。配合 `permits` 与 `switch` 模式匹配，实现**穷举式**分支。

```java
public sealed interface Payment permits CardPayment, WalletPayment, BankTransfer {
    BigDecimal amount();
}

public record CardPayment(String cardNo, BigDecimal amount) implements Payment {}
public record WalletPayment(String walletId, BigDecimal amount) implements Payment {}
public final class BankTransfer implements Payment {
    private final BigDecimal amount;
    // ...
    @Override public BigDecimal amount() { return amount; }
}
```

子类必须是 `final`、`sealed` 或 `non-sealed`。与 `switch` 组合时，编译器可检查是否覆盖所有分支。

## 4. Pattern Matching

### 4.1 instanceof（JDK 16+）

```java
// 旧写法
if (obj instanceof String) {
    String s = (String) obj;
    System.out.println(s.length());
}

// 新写法
if (obj instanceof String s && s.length() > 3) {
    System.out.println(s.toUpperCase());
}
```

### 4.2 switch 模式匹配（JDK 21 正式）

```java
static String describe(Object obj) {
    return switch (obj) {
        case null -> "null";
        case Integer i when i > 0 -> "positive int: " + i;
        case Integer i -> "non-positive int: " + i;
        case String s -> "string len=" + s.length();
        case List<?> list when list.isEmpty() -> "empty list";
        case List<?> list -> "list size=" + list.size();
        default -> obj.getClass().getSimpleName();
    };
}
```

`case null` 在 21 中可直接写在 switch 里，无需额外 `if`。

## 5. Text Blocks 与 Switch Expressions

### 5.1 文本块（JDK 15+）

```java
String json = """
        {
          "name": "demo",
          "version": 1
        }
        """;

String sql = """
        SELECT u.id, u.username
        FROM users u
        WHERE u.status = 'ACTIVE'
        ORDER BY u.created_at DESC
        """;
```

缩进以闭合 `"""` 的位置为准；`\` 可去除行尾换行。

### 5.2 Switch 表达式（JDK 14+）

```java
// 语句 → 表达式，必须穷尽或 default
String level = switch (score) {
    case 90, 100 -> "A";
    case 80 -> "B";
    case 70 -> "C";
    default -> "D";
};

// yield 用于代码块分支
int days = switch (month) {
    case 1, 3, 5, 7, 8, 10, 12 -> 31;
    case 2 -> {
        boolean leap = Year.isLeap(Year.now().getValue());
        yield leap ? 29 : 28;
    }
    default -> 30;
};
```

## 6. 虚拟线程（Virtual Threads，JDK 21）

Project Loom 成果：轻量级线程，由 JVM 调度，适合 **I/O 密集**（HTTP、DB、MQ），不适合 CPU 密集计算。

```java
// 方式一：直接创建
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    List<Future<String>> futures = IntStream.range(0, 10_000)
            .mapToObj(i -> executor.submit(() -> fetchUrl("https://api.example.com/" + i)))
            .toList();
    for (Future<String> f : futures) {
        f.get();
    }
}

// 方式二：Spring Boot 3.2+ 一行开启
// spring.threads.virtual.enabled=true
```

**与平台线程对比**：

| 维度 | 平台线程 | 虚拟线程 |
|------|----------|----------|
| 内存占用 | ~1MB/线程 | ~KB 级 |
| 创建成本 | 高 | 极低 |
| 适用场景 | CPU 密集、少量长任务 | 高并发 I/O |
| 注意 | 传统线程池模型 | 避免 `synchronized` 内长时间 I/O（会 pin 载体线程） |

## 7. Structured Concurrency（预览/孵化，21 一带）

结构化并发把子任务生命周期绑定到父作用域：父任务结束则子任务全部取消，避免"孤儿线程"。

```java
// JDK 21+ StructuredTaskScope（API 可能随版本微调）
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
  Subtask<String> user = scope.fork(() -> userService.findById(id));
  Subtask<List<Order>> orders = scope.fork(() -> orderService.listByUser(id));

  scope.join();
  scope.throwIfFailed();

  return new UserProfile(user.get(), orders.get());
}
```

Spring 6.1+ 提供 `TaskExecutor` 适配；生产环境建议关注 JDK 小版本 Release Notes 中 API 稳定度。

## 8. Sequenced Collections（JDK 21）

统一"有序集合"的首尾访问 API，解决 `List`/`Deque`/`LinkedHashSet` 接口不一致问题。

```java
SequencedCollection<String> seq = new ArrayList<>(List.of("a", "b", "c"));

seq.addFirst("z");   // [z, a, b, c]
seq.addLast("d");    // [z, a, b, c, d]
seq.getFirst();      // z
seq.getLast();       // d
seq.reversed();      // 逆序视图
```

`SequencedMap` 同理：`firstEntry()`、`lastEntry()`、`pollFirstEntry()`。

## 10. 从 Java 8/11 迁移清单

### 10.1 构建与依赖

```xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <configuration>
        <release>21</release>
    </configuration>
</plugin>
```

- 移除 `javax.*` → 换 `jakarta.*`（Spring Boot 3 已强制）。
- 检查反射：JDK 17+ 强封装模块，需 `--add-opens` 或升级库版本。
- 废弃 API：`SecurityManager`、`Thread.stop` 等应清理。

### 10.2 代码现代化（可渐进）

1. DTO 改 Record（无继承需求的场景）。
2. `instanceof` + 强制转型 → 模式匹配。
3. 长 `if-else` / 旧 `switch` → `switch` 表达式 + sealed。
4. 线程池高并发 I/O → 虚拟线程（压测后上线）。

### 10.3 运行参数示例

```bash
java -XX:+UseZGC \
     -Xms512m -Xmx2g \
     -jar app.jar
```

## 11. 选型结论

| 场景 | 建议版本 |
|------|----------|
| 2026 年新微服务 / Spring Boot 3.4+ | **Java 21** |
| 企业合规要求"已充分验证" | Java 17 可接受，规划 21 路线图 |
| 遗留 Tomcat 8 / Spring 4 | 先评估框架升级，不要只升 JDK |
| 需要虚拟线程 + 最新 GC | **Java 21** |

Java 17 奠定了现代语法基础（Records、Sealed、Text Blocks），Java 21 在此基础上提供**虚拟线程**与**有序集合**等生产级能力。除非有明确的中间件兼容性阻碍，新项目没有理由停留在 17。
