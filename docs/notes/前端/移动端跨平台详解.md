#### 1. 移动端跨平台概述

移动端跨平台开发是指使用一套代码同时开发多个平台（iOS、Android、Web）的应用程序。这种开发方式可以显著降低开发成本，提高开发效率，同时保持较好的用户体验。

**主要优势**：

- **代码复用**：一套代码多平台运行
- **开发效率**：减少重复开发工作
- **维护成本**：统一维护和更新
- **快速迭代**：同时支持多平台功能更新

**技术选型考虑因素**：

- **性能要求**：原生性能 vs 跨平台性能
- **开发效率**：开发速度 vs 代码质量
- **用户体验**：原生体验 vs 跨平台体验
- **生态支持**：社区活跃度和第三方库支持

#### 2. React Native 详解

##### 2.1 核心特性

React Native 是 Facebook 开发的跨平台移动应用框架，使用 JavaScript 和 React 语法，通过原生组件桥接实现跨平台开发。

**主要特点**：

- **原生性能**：使用原生 UI 组件
- **热重载**：开发时实时预览修改
- **组件化**：丰富的第三方组件库
- **社区活跃**：大量开源资源和社区支持

```dart
// lib/screens/product_list_screen.dart
import 'package:flutter/material.dart';
import '../models/product.dart';
import '../services/product_service.dart';
import '../widgets/product_card.dart';

class ProductListScreen extends StatefulWidget {
  @override
  _ProductListScreenState createState() => _ProductListScreenState();
}

class _ProductListScreenState extends State<ProductListScreen> {
  final ProductService _productService = ProductService();
  List<Product> _products = [];
  bool _isLoading = false;
  String? _error;

  @override
  void initState() {
    super.initState();
    _loadProducts();
  }

  Future<void> _loadProducts() async {
    setState(() {
      _isLoading = true;
      _error = null;
    });

    try {
      final products = await _productService.getProducts();
      setState(() {
        _products = products;
        _isLoading = false;
      });
    } catch (e) {
      setState(() {
        _error = e.toString();
        _isLoading = false;
      });
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text('产品列表'),
        actions: [
          IconButton(
            icon: Icon(Icons.refresh),
            onPressed: _loadProducts,
          ),
        ],
      ),
      body: _buildBody(),
    );
  }

  Widget _buildBody() {
    if (_isLoading) {
      return Center(child: CircularProgressIndicator());
    }

    if (_error != null) {
      return Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text('加载失败: $_error'),
            SizedBox(height: 16),
            ElevatedButton(
              onPressed: _loadProducts,
              child: Text('重试'),
            ),
          ],
        ),
      );
    }

    if (_products.isEmpty) {
      return Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Icon(Icons.inbox, size: 64, color: Colors.grey),
            SizedBox(height: 16),
            Text('暂无产品', style: TextStyle(fontSize: 18, color: Colors.grey)),
          ],
        ),
      );
    }

    return RefreshIndicator(
      onRefresh: _loadProducts,
      child: GridView.builder(
        padding: EdgeInsets.all(16),
        gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
          crossAxisCount: 2,
          childAspectRatio: 0.75,
          crossAxisSpacing: 16,
          mainAxisSpacing: 16,
        ),
        itemCount: _products.length,
        itemBuilder: (context, index) {
          return ProductCard(
            product: _products[index],
            onTap: () => _navigateToProductDetail(_products[index]),
          );
        },
      ),
    );
  }

  void _navigateToProductDetail(Product product) {
    Navigator.pushNamed(
      context,
      '/product-detail',
      arguments: product,
    );
  }
}
```

```javascript
// pages/index/index.js
Page({
    data: {
        banners: [],
        categories: [],
        products: []
    },

    onLoad() {
        this.loadBanners();
        this.loadCategories();
        this.loadProducts();
    },

    onPullDownRefresh() {
        Promise.all([
            this.loadBanners(),
            this.loadCategories(),
            this.loadProducts()
        ]).then(() => {
            wx.stopPullDownRefresh();
        });
    },

    async loadBanners() {
        try {
            const banners = await wx.cloud.callFunction({
                name: 'getBanners'
            });
            this.setData({banners: banners.result.data});
        } catch (error) {
            console.error('加载轮播图失败:', error);
        }
    },

    async loadCategories() {
        try {
            const categories = await wx.cloud.callFunction({
                name: 'getCategories'
            });
            this.setData({categories: categories.result.data});
        } catch (error) {
            console.error('加载分类失败:', error);
        }
    },

    async loadProducts() {
        try {
            const products = await wx.cloud.callFunction({
                name: 'getProducts',
                data: {limit: 10}
            });
            this.setData({products: products.result.data});
        } catch (error) {
            console.error('加载产品失败:', error);
        }
    },

    onBannerTap(e) {
        const banner = e.currentTarget.dataset.item;
        if (banner.linkType === 'product') {
            wx.navigateTo({
                url: `/pages/product/product?id=${banner.linkId}`
            });
        }
    },

    onCategoryTap(e) {
        const category = e.currentTarget.dataset.category;
        wx.navigateTo({
            url: `/pages/product/product?category=${category.id}`
        });
    },
```

#### 5. Electron 跨平台桌面应用

##### 5.1 核心特性

Electron 是 GitHub 开发的跨平台桌面应用框架，使用 Web 技术（HTML、CSS、JavaScript）构建桌面应用。

**主要特点**：

- **跨平台**：支持 Windows、macOS、Linux
- **Web 技术**：使用熟悉的 Web 开发技术
- **原生功能**：访问操作系统 API
- **自动更新**：支持应用自动更新

##### 5.2 项目搭建

**项目初始化**：

```bash
# 创建项目目录
mkdir my-electron-app
cd my-electron-app

# 初始化 npm 项目
npm init -y

# 安装 Electron
npm install electron --save-dev

# 安装其他依赖
npm install electron-builder --save-dev
npm install electron-updater --save-dev
```

**项目结构**：

```
my-electron-app/
├── src/
│   ├── main/           # 主进程代码
│   ├── renderer/       # 渲染进程代码
│   └── shared/         # 共享代码
├── dist/               # 构建输出
├── package.json        # 项目配置

```

```javascript
const {app, BrowserWindow, Menu, ipcMain} = require('electron');
const path = require('path');

let mainWindow;

function createWindow() {
    mainWindow = new BrowserWindow({
        width: 1200,
        height: 800,
        webPreferences: {
            nodeIntegration: true,
            contextIsolation: false,
            enableRemoteModule: true
        },
        icon: path.join(__dirname, '../assets/icon.png'),
        show: false
    });

    // 加载应用
    mainWindow.loadFile(path.join(__dirname, '../renderer/index.html'));

    // 显示窗口
    mainWindow.once('ready-to-show', () => {
        mainWindow.show();
    });

    // 窗口关闭事件
    mainWindow.on('closed', () => {
        mainWindow = null;
    });

    // 开发环境打开开发者工具
    if (process.env.NODE_ENV === 'development') {
        mainWindow.webContents.openDevTools();
    }
}

// 应用准备就绪
app.whenReady().then(() => {
    createWindow();

        if (BrowserWindow.getAllWindows().length === 0) {
```

#### 6. 技术选型建议

##### 6.1 移动端跨平台

**React Native**：

- **适用场景**：需要接近原生性能的应用
- **优势**：原生组件、热重载、社区活跃
- **劣势**：学习曲线陡峭、调试复杂

**Flutter**：

- **适用场景**：追求最佳性能的跨平台应用
- **优势**：自绘引擎、单一代码库、Google 支持
- **劣势**：Dart 语言学习成本、生态相对较小

**小程序**：

- **适用场景**：轻量级应用、快速上线
- **优势**：无需安装、用户获取成本低
- **劣势**：功能限制、平台依赖

##### 6.2 桌面端跨平台

**Electron**：

- **适用场景**：Web 应用桌面化、快速开发
- **优势**：Web 技术栈、跨平台、生态丰富
- **劣势**：资源占用高、性能相对较低

**Tauri**：

- **适用场景**：追求轻量级的桌面应用
- **优势**：资源占用低、性能好、安全性高
- **劣势**：生态相对较小、学习成本较高
